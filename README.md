# Pikoora

Pikoora is a modern educational streaming platform designed to make learning engaging, interactive, and accessible for children. It provides a polished streaming-style interface where young learners can explore educational content across ABC & Learning, Numbers & Counting, Poems & Rhymes, Stories, and Fun Learning.

The platform features a cinematic splash screen, responsive navigation, featured content carousel, category-based browsing, interactive video cards, search functionality, smooth animations, and embedded online video playback. Pikoora is built with React, Vite, Tailwind CSS, Framer Motion, and Lucide React, with a focus on clean UI, 
responsive design, accessibility, and maintainable frontend architecture.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- Lucide React
- YouTube Embed Integration

## Key Features

- Modern streaming-inspired user interface
- Responsive design for desktop, tablet, and mobile
- Educational content organized by category
- Featured hero carousel with smooth transitions
- Interactive video cards
- Search and content discovery
- Embedded online video playback
- Cinematic splash screen
- Smooth animations and micro-interactions
- Dark interface with Pikoora's signature red branding
